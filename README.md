## 📌 C# Generics & Extension Methods Demo

This project demonstrates the use of **Generics**, **Custom Collections**, and **Extension Methods** in C#.

### ✨ Features
- Implementation of a custom generic list (`CustomSuperList<T>`)
- Dynamic array resizing (similar to `List<T>`)
- Generic `Add` and `RemoveAt` methods
- Extension methods for `List<T>`
  - `InsertToFront<T>()`
  - `ConvertTo<TSource, TTarget>()`
- Type inference vs explicit generic type declaration

### 🧠 Concepts Covered
- Generics in classes and methods
- Extension Methods
- Type inference
- Explicit casting & `Convert.ChangeType`
- Exception handling
- Memory management with arrays

### 🛠 Technologies
- C#
- .NET
- Console Application

### 🎯 Purpose
Educational project for learning advanced C# concepts and internal mechanics of collections.
